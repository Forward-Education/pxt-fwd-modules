# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com), but without change categorization.

## [1.1.7] 08/06/2026

- fixed naming of locale files for voice and vision ai

## [1.1.6] 08/06/2026

- added locales folders

## [1.1.5]

- refactored AI voice and vision modules for extension approval

## [1.1.4]

- fixed AI voice block id's clashing with DFRobot extension

## [1.1.3]

- fixed AI voice and vision module names clashing with kit extension names

## [1.1.2]

- changed LED ring brightness blocks to use a visually-determined calibration curve
- flipped float sensor state blocks
- limited LCD number printing magnitude
- updated I2C and AI voice/vision code

## [1.1.1]

- added a pause to driving blocks

## [1.1.0]

- removed isEnabled and setEnabled servo blocks
- changed driving blocks to simplify user experience
- updated fwd-base and jacdac dependencies

## [1.0.13]

- Added PIR module blocks
- Added AI vision and voice blocks
- Explicitly defined block order using weight property rather than relying on order of declaration
- Updated pxt-fwd-base dependencies to v1.0.12
- Removed update-dependency script, just use vs code search and replace instead
